“Listen2WP is a free accessibility plugin that provides text-to-speech functionality through a fully customizable Gutenberg block.

== Description ==

Listen2WP is a versatile and fully customizable accessibility plugin designed to enhance your WordPress site with text-to-speech capabilities. It integrates a simple and user-friendly Gutenberg block that allows content to be read aloud to users, promoting inclusivity and accessibility.

Key Features:
-	Customizable Controls: Configure the text and icons for different buttons like “Play”, “Pause”, “Resume”, and “Stop”. Choose from various icon styles, including normal and rounded icons, to match your website’s design.
- Text-to-Speech: Easily play, pause, resume, or stop text-to-speech functions with intuitive on-screen buttons.
	•	Personalized Appearance: Adjust the button styles with customizable text and background colors, border styles, and padding for a perfect match with your site’s theme.
	•	Responsive Layout: The plugin adapts to different screen sizes, ensuring that your accessibility options are available across all devices.
	•	Icon Customization: Choose the ideal icons for each action through a modal interface, ensuring you can easily match the visual style of your site.
	•	Advanced Accessibility: By offering text-to-speech functionality, Listen2WP significantly improves accessibility for users with visual impairments or reading difficulties.

User-Friendly Editor Integration:
	•	Customizable Text: Easily modify the button text labels, such as “Play Text”, “Pause Text”, and more directly within the block editor.
	•	Color Settings: Adjust the text and background colors to ensure visibility and contrast for all users.
	•	Border and Padding Adjustments: Fine-tune the border radius, border width, and padding of the buttons to ensure a cohesive and polished design.

With Listen2WP, you can effortlessly integrate text-to-speech functionality into your website, improving the overall user experience and making your content more accessible for all.

== Installation ==

Install Listen2WP either via the WordPress plugin directory or by uploading the files to your server at wp-content/plugins.

You can refer to our getting started article to know more.

== Frequently Asked Questions ==

= How can I customize the text and icons on the buttons? =

You can easily customize the text for buttons like “Play”, “Pause”, “Resume”, and “Stop” directly within the WordPress block editor. For the icons, you can choose from various predefined styles (normal and rounded) through a modal interface, allowing you to select the icon that best matches your design.

= Is Listen2WP mobile-friendly? =

Yes, Listen2WP is fully responsive and automatically adjusts to all devices, including smartphones and tablets. The buttons are easy to use on smaller screens, ensuring that the text-to-speech functionality is accessible to all visitors, no matter where they are.

= Is this plugin compatible with other accessibility plugins? =

Yes, Listen2WP is designed to work harmoniously with other accessibility plugins. It doesn’t interfere with the functionality of other tools and provides an additional option to enhance the user experience, especially for people with visual impairments or reading difficulties.

= Are the icons provided in Listen2WP free to use? =

Yes, all the icons included with Listen2WP are free to use and distributed under a license that allows for both personal and commercial use. You do not need to worry about any additional costs or licensing fees for these icons.
